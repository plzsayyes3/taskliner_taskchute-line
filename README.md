# taskliner_taskchute-line

TaskLiner / taskchute-line の考え方を、Obsidian プラグインではなく **単体HTMLで動かす実験版**です。

## 現在の構成

- `index.html` — GitHub Pages の入口。TaskLiner本体を表示し、設定UIを重ねる
- `app.html` — TaskLinerのビュー・操作本体
- `taskliner_taskchute-line.html` — 直接アクセス時に `index.html` へ戻す互換入口
- GitHub同期の既定保存先 — `plzsayyes3/mynotebook` の `task-data` branch / `09_taskchute`

## 現在できること

- 日付ごとのタスク管理
- 現在時刻を `HH:MM:SS` で毎秒表示
- タスク追加と見積時間の入力
- 実行中タスクのタイトル・開始時刻・経過時間を上部に表示
- 上部の実行中カードからタスクを終了
- タスク開始 / 終了
- 前回の終了時刻から開始
- 実行中タスクを開始した際、既存の実行中タスクを終了
- 完了 / 保留 / リセット
- 上下移動
- 翌日へ移動
- 前日の未完了タスクを持ち越し
- 実績時間・進捗・残り見積の表示
- 完了済みタスクの表示 / 非表示切替
- `## 見出し` を使ったセクション表示
- セクション単位の非表示 / 再表示
- TaskLiner風Markdownへの書き出し
- Markdownからの取り込み
- `.md` ダウンロード
- GitHub tokenを使ったMarkdownの読込 / 保存
- 変更後1分間操作がなければGitHubへ自動保存
- 上部の `pull` から現在日のGitHubデータを再読込
- 上部の `sync` から未保存変更を手動保存
- 未保存状態で日付移動する場合、GitHub保存完了後に約1秒待ってから移動
- タブやアプリを離れる際、未保存ならGitHub保存を試行
- `保存済み / 未保存 / 保存中… / 競合あり / 保存失敗` の状態表示

## 画面上部

上部は、日常的に確認・操作する内容だけを優先して配置しています。

- `TaskLiner` の横に秒付き現在時刻を表示
- 前日 / 日付 / 翌日 / 今日をコンパクトに配置
- 完了数・進捗・実績・残り見積を小さく表示
- その下に `実行中` と `タスク追加` を配置
- 実行中タスクは経過時間を毎秒更新し、上部から直接終了可能
- 通常操作列は `前日から持越 / 完了を非表示・表示 / セクション` に限定
- Markdownのコピー・ダウンロード・取込は通常列から外し、画面下部の `Markdown / 詳細` に退避

タスク行も、`開始 / 前回から / 終了` のような頻度の高い操作を表に出し、`保留 / リセット / 上下移動 / 翌日 / 削除` は `その他` にまとめています。

## セクション

Markdownのレベル2見出しをセクションとして扱います。

```md
## A
- [ ] タスク1
- [ ] タスク2

## B
- [ ] タスク3
```

画面では `A`、`B` の見出しごとにタスクを表示します。

各セクション見出しの `非表示` を押すと、**そのセクションの見出しとタスクをまとめてビューから隠します**。タスク自体は削除せず、MarkdownやGitHub保存内容にも残ります。

上部の `セクション` ボタンから、非表示にしたセクションを再表示できます。非表示状態はブラウザの `localStorage` に保存し、同名セクションでは日付を切り替えても設定を維持します。

## 設定

画面右下の **`⚙`** がHTML版TaskLinerの設定入口です。

現在は設定パネル内に `GitHub同期` を置いています。今後、表示・保存・同期などの設定もこの歯車へ集約します。

## 保存方式

通常操作はブラウザの `localStorage` へ即時保存します。

GitHub同期を使う場合は、画面右下の `⚙` を開き、`GitHub同期` から日別MarkdownをGitHubへ保存できます。また、通常画面上部の `pull` で現在日をGitHubから再読込し、`sync` で現在日の未保存変更をすぐGitHubへ保存できます。

### Auto Save v1

タスクの追加・開始・終了・編集・移動などでTaskLinerのローカルデータが変わると、その日を `未保存` として記録します。

- `localStorage` への保存は従来どおり即時
- 最後の変更から1分間、新しい変更がなければGitHubへ自動保存
- 上部の `sync` を押すと、未保存の現在日をすぐGitHubへ保存
- すでに `保存済み` の場合、上部の `sync` は不要なGitHub更新を行わない
- 上部の `pull` は現在日のGitHubファイルを読み込み、未保存変更がある場合は破棄確認を行う
- 未保存のまま `前日 / 翌日 / 今日 / 日付指定` で移動しようとすると、先にGitHubへ保存
- 保存成功時は `保存しました` を表示し、約1秒後に日付を移動
- 保存に失敗または競合を検出した場合は、そのまま現在日に留まる
- タブが非表示になった場合も、未保存ならGitHub保存を試行
- 別日に対する変更（例: `翌日へ移動`）も未保存日として記録し、その日を開いた時に自動保存対象になる

未保存日の情報と、直前に確認したGitHubファイルのSHAはブラウザの `localStorage` に保持します。このためページを再読み込みしても、自動保存の競合判定を継続できます。

自動保存は競合時に無断で上書きしません。GitHub側に前回確認後の変更がある場合や、まだ基準SHAを持っていない既存ファイルの場合は `競合あり` とし、`pull` または設定内の手動保存で確認してから処理します。

ブラウザを閉じる・再読み込みする操作そのものを1秒遅延させる処理は入れていません。ブラウザ制約上、ここは確実な待機を保証できないため、Auto Save v1ではタブ非表示時の保存試行までとしています。

既定値:

```text
Repository: plzsayyes3/mynotebook
Branch: task-data
Folder: 09_taskchute
```

保存先は次の形式です。

```text
09_taskchute/YYYY-MM-DD.md
```

例:

```text
09_taskchute/2026-09-10.md
```

HTML本体を置く `plzsayyes3/taskliner_taskchute-line` の `main` と、タスクデータを置く `plzsayyes3/mynotebook` の `task-data` branch を分離しています。そのため、タスク保存のたびにGitHub Pagesを再デプロイしません。

### GitHub token

Fine-grained Personal Access Token を使用します。

必要権限:

```text
Repository access: plzsayyes3/mynotebook
Contents: Read and write
```

TokenはHTMLやGitHubリポジトリには保存せず、**このブラウザの `localStorage` に保存**します。そのため、ブラウザを閉じても次回アクセス時に再利用できます。

`Tokenを消去` を押すと、`localStorage` からTokenを削除します。

> Tokenを保存するブラウザは自分専用端末を前提とします。Fine-grained token は対象Repositoryだけに限定し、必要最小限の `Contents: Read and write` 権限にしてください。

### 公開範囲

HTML本体の `plzsayyes3/taskliner_taskchute-line` は public repository です。一方、既定のタスク保存先 `plzsayyes3/mynotebook` は private repository として運用し、タスクMarkdownをHTML本体の公開Repositoryへ保存しない構成にしています。

設定パネルでは任意の `owner/repo`、branch、folderを指定できます。保存先を変更する場合は、接続確認でpublic/privateとBranchの存在を確認してください。

## Markdown例

```md
## 午前
- [ ] タスク名 (25m)
- [/] 実行中タスク (25m) 【09:00-】

## 午後
- [x] 完了タスク (25m) 【13:00-13:25 / 25m】
- [>] 保留タスク (25m)
```

見積時間は `(25m)` を標準形式として書き出します。互換性のため `⏳25m` も読み取れますが、次回の表示・保存時には `(25m)` へ正規化します。

```md
- [ ] 新規タスク (25m)
- [/] 実行中タスク (25m) 【09:00-】
```

### 既存Markdownの保持

`mynotebook/task-data/09_taskchute` の既存MarkdownをHTML版で扱っても、タスクとして解釈しない行を捨てないようにしています。

保持対象には、次のような内容を含みます。

- `# YYYY-MM-DD` などのレベル1見出し
- AIアドバイスや通常のMarkdown本文
- 空のセクション見出し
- タスク直下のインデントされた子メモ
- 空行やその他の非タスク行

チェックボックスのないトップレベルの箇条書きもタスクとして読み取ります。未操作のまま書き戻す場合は、チェックボックスなしの表記を維持します。

```md
- 20:00-21:00 予定
```

また、時刻を持たない完了タスクは完了状態として扱いつつ、存在しない `00:00-00:00` を補わず、そのまま保持します。

```md
- [x] 発育測定
```

## GitHub同期の使い方

1. GitHubでFine-grained Personal Access Tokenを作る
2. Pagesを開く
3. 右下の `⚙` を押して設定を開く
4. `GitHub同期` のToken欄へ入力する
5. `接続確認` を押す
6. 初回または基準SHAがない既存日では `GitHubから読込` または上部の `pull` を行う
7. 以後は通常操作後の自動保存、上部の `sync`、または必要に応じて設定内の `GitHubへ保存` を使う

入力したTokenは `localStorage` に保存され、次回アクセス時に復元されます。

接続確認ではRepositoryだけでなく、指定Branchの存在とprivate/publicも確認します。

GitHub上のファイルが前回読込後に更新されていた場合は、自動保存では上書きせず競合として停止します。手動保存では確認ダイアログを出します。
