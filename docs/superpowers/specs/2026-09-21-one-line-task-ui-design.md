# TaskLiner 1行タスクUI デザイン仕様

## 目的

TaskLinerの各タスクを通常時は1行で扱い、選択したタスクだけを2行へ展開して操作できるようにする。日々の一覧の密度を保ちながら、既存の開始・終了・保留・翌日・並べ替え・削除などの機能を失わない。

## 採用する表示モデル

### 通常行

通常時は次の情報だけを表示する。

- 状態ボタン
- タスク名
- 見積時間・開始終了時刻などの短いメタ情報
- ユーザーが表示設定で選んだ最小限の補助情報

操作ボタンは通常行には表示しない。

### 選択行

タスク行をクリックまたはタップすると、その行だけが2行に展開する。

- 1行目：通常行と同じタスク情報
- 2行目：選択された操作ボタン

他の行は移動・展開しない。別の行を選択した場合は前の行を通常行へ戻し、新しい行だけを展開する。

## 操作表示設定

表示する操作は設定画面で個別に選択できる。初期値は、日常の操作を妨げない最小構成とする。

| 表示文字 | 意味 | 対応する既存機能 |
|---|---|---|
| 済 | 完了・完了解除 | status button |
| 始 | 開始 | startTask |
| 終 | 終了 | endTask |
| 時 | 時刻指定 | startTaskAt / endTaskAt |
| 保 | 保留 | deferTask |
| 翌 | 翌日へ移動 | moveTomorrow |
| 上 | 上へ移動 | moveTask(id, -1) |
| 下 | 下へ移動 | moveTask(id, 1) |
| 削 | 削除 | deleteTask |
| … | その他 | 既存のその他メニュー |

文字表示は暫定UIであり、内部では操作キーと表示文字を分離する。将来アイコンへ変更してもタスクデータや操作ロジックを変更しない。

すべての文字ボタンには`title`と`aria-label`を付け、1文字表示による意味の分かりにくさを補う。

## Repeat表示

Repeatは通常行でも識別できるようにするが、現在の「↻ Repeat」のようなラベル表示はやめ、薄い`↻`だけをメタ情報内に表示する。選択行や詳細表示では必要に応じて「繰り返し」の説明を参照できる。

## 設定の保存

操作表示設定と選択状態はまず端末内のlocalStorageに保存する。既存のGitHub同期設定、Daily Markdown形式、Master/Repeatデータ形式は変更しない。

## レスポンシブ方針

- デスクトップ：選択行の下段に操作を表示する。
- モバイル：タップで同じ2行表示を行い、ホバーには依存しない。
- 操作ボタンは1文字幅を基本とし、タップ可能な最小サイズを確保する。

## 非対象

- アイコンデザインそのもの
- Daily Markdownの保存形式の変更
- Repeat生成ロジックの変更
- GitHub同期方式の変更
- sample.htmlの本番化

## 完了条件

1. 通常行が1行表示になる。
2. 選択行だけが2行に展開する。
3. 表示操作のON/OFFが設定画面から変更でき、再読込後も保持される。
4. 既存のタスク操作がすべて実行できる。
5. Repeat表示が薄い`↻`になり、一覧の主張を抑えられる。
6. 既存テストとUI構文テストが成功する。
